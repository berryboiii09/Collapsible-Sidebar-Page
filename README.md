# Collapsible-Sidebar-Page
A responsive webpage featuring a collapsible sidebar built with HTML, CSS, and JavaScript. The sidebar smoothly opens and closes using a toggle button and adapts to different screen sizes for a consistent user experience.

## Key Features

Collapsible sidebar with toggle animation

Navigation links with icons and logo placeholder

Fully responsive layout for desktop and mobile

Smooth transitions using CSS and JavaScript
